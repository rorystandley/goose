# Security Policy

## Supported Versions

Security fixes are applied to the latest version on the default development branch.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use one of these private channels:

- GitHub Security Advisory (preferred):
  https://github.com/rorystandley/goose/security/advisories/new
- Maintainer contact channels listed in this repository

When reporting, include:

- A clear description of the issue and impact
- Steps to reproduce or a proof of concept
- Affected files/components and suggested fix (if known)

You can expect:

- Acknowledgement within a reasonable timeframe
- Investigation and triage
- Coordinated disclosure once a fix is available
